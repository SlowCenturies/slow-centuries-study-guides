# Corrections and suggestions

Thank you for helping keep these guides accurate.

- **Found an error?** Open an issue. Say which guide and which line, what's wrong, and give a source (a museum record, a published book or article).
- **Broken link?** Open an issue with the link. If you know the new address, include it.
- **Teaching idea?** Activities and discussion questions that worked in your class are welcome.

Accepted corrections are noted in the guide's history and credited by name if you'd like.
