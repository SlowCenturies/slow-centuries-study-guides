# For teachers

## How each guide is built

- **Fact-checked script.** Every episode script goes through a fact-check pass before recording. Claims that historians still debate are marked as debated, both in the video and in the guide.
- **Primary sources first.** Links go to the museum, library or archive that holds the object, or to the original publication. Secondary sources are labelled.
- **Plain language.** Guides are written at about a grade 7 reading level so they work for a wide range of students.

## A suggested 30-minute lesson

1. **Warm-up (2 min).** Ask: "What's a set of instructions you followed today?"
2. **Watch (13 min).** Students note three dates and one surprise.
3. **Activity (10 min).** Use the hands-on activity in the guide.
4. **Discuss (4 min).** Pick one discussion question.
5. **Exit ticket (1 min).** "One thing that hasn't changed in 4,000 years is…"

## Accessibility

Each episode has English captions on YouTube. Guides are plain HTML pages that work with screen readers and print cleanly from any browser.
